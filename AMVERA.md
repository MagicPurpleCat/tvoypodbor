# Запуск на Amvera

На Amvera будет два проекта:

1. **База данных** PostgreSQL — хранит пользователей, резюме, подписки.
2. **Приложение** — бот, Mini App и всё остальное в одном контейнере.

Redis не нужен. Без него лимиты запросов хранятся в памяти программы и обнуляются при перезапуске: в этот день у людей снова будет 5 бесплатных запросов. На старте это не критично. Redis можно подключить позже одной настройкой `REDIS_URL`.

Названия кнопок на сайте Amvera могут немного отличаться от написанных здесь.

---

## 1. База данных

1. На amvera.ru → «Создать» → «База данных» → **PostgreSQL**.
2. Название: `tvoypodbor-db`. Тариф — самый младший.
3. Задайте имя базы `tvoypodbor`, пользователя `tvoypodbor` и пароль. Пароль можно взять из `.env`, строка `POSTGRES_PASSWORD`.
4. После создания откройте базу и найдите **адрес для подключения** (host). Скопируйте его.

Из этих данных собирается строка подключения:

```
postgres://tvoypodbor:ПАРОЛЬ@АДРЕС:5432/tvoypodbor
```

Это значение `DATABASE_URL` для шага 3.

## 2. Проект приложения

1. «Создать» → «Приложение». Название: `tvoypodbor`. Тариф — от 512 МБ памяти.
2. Способ загрузки — **через Git**. Amvera покажет адрес репозитория, понадобится на шаге 4.
3. Откройте проект → «Домены» → добавьте **бесплатный домен**. Получится адрес вида `https://tvoypodbor-ваше-имя.amvera.io`. Это адрес и бота, и приложения.

## 3. Переменные

В проекте приложения → «Переменные». Добавьте каждую строку отдельно. Если есть выбор «переменная / секрет», то `BOT_TOKEN`, `BOT_WEBHOOK_SECRET`, `PLATEGA_SECRET` и `DATABASE_URL` добавляйте как **секрет**.

| Имя | Значение |
|---|---|
| `PUBLIC_URL` | адрес из шага 2, например `https://tvoypodbor-ваше-имя.amvera.io` (без `/` в конце) |
| `DATABASE_URL` | строка из шага 1 |
| `BOT_TOKEN` | ключ бота от @BotFather |
| `BOT_USERNAME` | адрес бота без @ |
| `BOT_WEBHOOK_SECRET` | скопируйте из `.env` |
| `WEBAPP_SHORT_NAME` | `app` |
| `HH_USER_AGENT` | `TvoyPodbor/1.0 (ваша@почта.ru)` |
| `PLATEGA_MERCHANT_ID` | из кабинета Platega (можно позже) |
| `PLATEGA_SECRET` | из кабинета Platega (можно позже) |

`WEBAPP_URL`, `REDIS_URL`, `API_DOMAIN`, `APP_DOMAIN` **не добавляйте**: на Amvera они не нужны.

## 4. Загрузить код

Нужен Git — он уже стоит, если есть Git Bash. Откройте Git Bash в папке `ТвойПодбор` (правой кнопкой по папке → «Open Git Bash here») и выполните по очереди.

Один раз — подготовить код:

```bash
git init
```
```bash
git add .
```
```bash
git commit -m "ТвойПодбор"
```

Если на `git commit` Git пишет «Please tell me who you are», один раз выполните две команды и повторите `git commit`:

```bash
git config --global user.name "Ваше Имя"
```
```bash
git config --global user.email "ваша@почта.ru"
```

Связать с Amvera — вставьте адрес репозитория из шага 2:

```bash
git remote add amvera АДРЕС_РЕПОЗИТОРИЯ
```

Отправить:

```bash
git push amvera master
```

Git спросит логин и пароль — это логин и пароль от Amvera. Если ругается на `master`, попробуйте `git push amvera HEAD:master`.

Файл `.env` с паролями на Amvera не попадёт, так и задумано: настройки уже введены на шаге 3.

## 5. Проверить

1. В проекте на Amvera откройте «Логи сборки» и дождитесь конца, 3–5 минут.
2. В «Логах приложения» должно появиться `api on :3000`. Строка `REDIS_URL не задан…` — нормально.
3. Откройте в браузере `https://ваш-адрес.amvera.io/health`. Должно быть `{"ok":true}`. Если ошибка — проверьте `DATABASE_URL`.
4. Напишите боту `/start`. Должны прийти картинка, приветствие и кнопка.

## 6. Подключить Mini App в @BotFather

1. `/newapp` → выберите бота.
2. Название, описание, картинка `assets/miniapp-cover.png`.
3. URL — ваш адрес на Amvera.
4. Короткое имя — `app`, как в `WEBAPP_SHORT_NAME`.

Готово: кнопка в боте открывает приложение.

## Обновления

Когда что-то поменяли в коде:

```bash
git add .
```
```bash
git commit -m "изменения"
```
```bash
git push amvera master
```

Amvera сама пересоберёт и перезапустит проект, таблицы базы обновятся автоматически.

## Если не работает

| Что видно | Что проверить |
|---|---|
| Сборка упала | Пришлите мне текст из «Логов сборки» |
| В логах `ZodError` и название переменной | Эта переменная не заполнена или заполнена неверно |
| `/health` выдаёт ошибку | `DATABASE_URL`: адрес, пароль, имя базы |
| Бот молчит на `/start` | `PUBLIC_URL` должен начинаться с `https://`; после исправления перезапустите проект |
| Приложение пишет «Откройте приложение через бота» | Открывайте кнопкой в боте, а не ссылкой в браузере |
